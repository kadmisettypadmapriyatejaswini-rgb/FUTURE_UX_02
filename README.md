# Salon Appointment Booking Mobile App UI

## Project Overview

This project is a mobile application UI design for salon appointment booking created using Figma.
The application helps users easily browse salon services, select appointment slots, and confirm bookings through a simple and user-friendly interface.

## Target Users

- Salon customers
- Students
- Working professionals
- Salon owners

## Problem Statement

Traditional appointment booking often involves waiting, phone calls, and scheduling confusion.
This application simplifies the process by providing an easy digital booking experience.

## Solution

The mobile application allows users to:

- Browse salon services
- Select preferred appointment dates
- Choose available time slots
- Confirm appointments instantly

## Booking Flow Logic

1. Onboarding Screen
2. Login Screen
3. Homepage
4. Service & Time Selection
5. Booking Confirmation
6. Success Screen

## UX Decisions

### Simple Navigation
Users can complete bookings with minimal steps.

### Consistent Design
The same colors, typography, and buttons are used across all screens.

### Clear Call-To-Action
Important actions are highlighted through prominent buttons.

### Confirmation Feedback
Users receive immediate confirmation after booking.

## How This Design Improves User Experience

- Faster appointment scheduling
- Reduced waiting time
- Clear booking process
- Improved usability
- Better customer satisfaction
